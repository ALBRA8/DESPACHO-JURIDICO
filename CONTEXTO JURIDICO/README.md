## Reglas de mantenimiento

- GitHub y el código fuente de `ALBRA8/DESPACHO-JURIDICO` son la fuente de verdad de la implementación.
- Esta carpeta es la fuente de continuidad documental del proyecto, no un sustituto del código, de las fuentes oficiales ni de la evidencia.
- Distinguir siempre entre hechos verificados directamente, afirmaciones de informes existentes, inferencias y asuntos pendientes.
- Un informe que declara PASS no equivale a una auditoría independiente reproducida.
- No presentar normas, jurisprudencia, doctrina ni artículos reconstruidos como fuentes reales.
- Mantener separado el ADN universal de ALBRA del conocimiento específico de cada dominio.
- No incorporar secretos, credenciales, tokens, datos personales sensibles ni expedientes reales identificables.
- No iniciar la especialización contable hasta que se decida expresamente y exista una base universal suficientemente auditada.

## Convención de estado

Usar etiquetas explícitas: `VERIFIED`, `VERIFIED DOCUMENTATION`, `REPORTED`, `PARTIAL`, `UNVERIFIED`, `MISSING`, `PROPOSED`, `APPROVED`, `SUPERSEDED` y `HISTORICAL`.
