## 7. Pipeline soberano

```
USER REQUEST
   ↓
IDENTITY (auth context)
   ↓
CLASSIFICATION (albra.security.classification)
   ↓
POLICY (policy_state.get_state + kill_switch check)
   ↓
MEMORY CONTEXT (MemoryInterface.retrieve)
   ↓
REASONING.plan (intent detection)
   ↓
TOOL CALLS (cada uno vía ExecutionGuard fail-closed)
   ├─ RBAC check
   ├─ Autonomy ceiling check
   ├─ LegalGate verdict
   ├─ Circuit breaker check
   ├─ Data classification check
   ├─ HITL check (si aplica)
   └─ Dedup (solo si todo OK)
   ↓
REASONING.respond (vía ProviderRouter → LLM Provider)
   ├─ Sensitive data → local provider
   ├─ Provider failure → fallback mock
   └─ legal_question → rules_fallback (no LLM)
   ↓
LEGAL GATE final sobre response
   ↓
MEMORY WRITE (MemoryInterface.write con truth_level)
   ↓
AUDIT (record outtake)
   ↓
EXECUTION TRACE finish
   ↓
RESPONSE
```

**Runtime** es la autoridad orquestadora. `agent.process()` delega al Runtime para el loop plan-act-observe.
